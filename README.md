# 校园流感爆发空间随机 SEI2R 模型

这是一个用于校园流感传播模拟与控制策略比较的 Jupyter Notebook 项目，包含：

- 基于 H3N2 周数据的 ABC 方法估计 $R_0$
- 人口密度与 $R_0$ 的回归分析
- 校园多区域随机 SEI2R 模拟
- 疫苗、隔离和 Bang-Bang 联合控制策略搜索
- 模拟结果可视化

## 项目说明

甲型 H3N2 流感在高校校园中容易受到高密度聚集和功能区差异的影响，形成宿舍、教学楼或食堂等区域性传播。针对疫情初期病例少、离散度高，传统确定性模型参数估计容易失准的问题，本项目构建了融合潜伏期动力学和空间异质性的校园随机传播模型。

项目将校园划分为五个功能区，通过区域人口规模、密度倍数和接触率矩阵描述空间差异；通过 Reed-Frost 离散随机框架模拟感染、潜伏、发病和康复过程。模型以 WHO FluNet 的全球 H3N2 监测数据为基础，使用近似贝叶斯计算（ABC）逐国估计基础再生数 $R_0$，再以中国基准参数构建校园接触率矩阵。

本项目的核心是校园流感的最优控制。项目在确定性均值场近似下，将疫苗接种和病例隔离建模为两个 Bang-Bang 控制变量：控制启动时取 1，否则取 0。通过控制疫情根除时间、干预成本和累计感染规模，在有限时间窗口内搜索疫苗与隔离的最优启动和结束时刻。完整的建模论文见 `建模论文.pdf`。

## 最优控制方法

控制策略的求解流程如下：

1. **建立控制系统**：在校园多区域 SEI2R 模型中加入疫苗接种（$S\rightarrow R$）和病例隔离（$I\rightarrow R$）控制项。
2. **构造目标函数**：综合最小化疫情持续时间、控制成本和累计感染规模，使策略兼顾防控速度与资源投入。
3. **均值场求解**：用确定性均值场 ODE 近似随机系统，采用 Crank-Nicolson 二阶隐式格式和 Picard 不动点迭代计算受控轨迹。
4. **Bang-Bang 搜索**：将原本的时间函数优化转化为疫苗窗口和隔离窗口的切换时间搜索，比较不同控制组合的目标函数值。
5. **随机验证**：将最优控制方案与无控制、仅疫苗和仅隔离方案进行对比，评估有症状感染人数、疫情结束时间和累计感染规模。

### 主要结论

- 联合控制的目标是在较低干预成本下尽快使活跃感染者降至根除阈值。
- 疫苗接种应在疫情早期启动，以便在易感者较多时尽早阻断传播链。
- 隔离策略通常在有症状病例积累到可观测规模后启动，资源利用效率更高。
- 联合疫苗和隔离控制比单项控制更能缩短疫情持续时间并降低累计感染规模。
- 中国 H3N2 社区基准 $R_0$ 约为 1.57，按校园功能区密度加权后整体有效 $R_0$ 约为 2.20；宿舍区和食堂是重点控制区域。

## 数据来源与要求

本文使用世界卫生组织全球流感监测和应对系统（GISRS）维护的 FluNet 数据库，提取 H3N2（AH3）亚型的非零记录。经数据清洗后，共涵盖 175 个国家和地区，时间跨度为 1995 年 1 月至 2026 年 4 月，总计 57,457 条周级观测记录。

运行 notebook 所需的数据文件为 `data/AH3_non_zero.csv`，至少应包含以下字段：

- `ISO_WEEKSTARTDATE`：周起始日期
- `ISO_YEAR`、`ISO_WEEK`：ISO 年和周
- `COUNTRY_AREA_TERRITORY`：国家或地区名称
- `SPEC_PROCESSED_NB`：处理的样本数
- `AH3`：H3N2 阳性数
